# Our Little Universe ♡ (All Chapters Complete — Phase 4)

> A cozy romantic pixel-art indie game & interactive story website celebrating how two souls became each other's favorite person.

---

## ✨ Creative Direction
- **Aesthetic**: 70% pixel-art indie romance game, 30% kawaii aesthetic.
- **Color Palette**: Pastel pink, warm cream, soft peach, lavender, and pale sky blue with crisp retro pixel borders.
- **Rendering**: Crisp pixel art using `image-rendering: pixelated` and custom SVG sprite pixel geometry.
- **Audio Engine**: Synthesized Web Audio API 8-bit chiptune sound effects, heartbeat simulation, magic chime harp sweep, & cozy background melody (defaulted to **OFF**, never autoplays).

---

## 🌸 Characters & Pets
- **Boy**: Messy anime-style chocolate hair, blushing cheeks, cozy oversized lavender hoodie, expressive emotions (shy blush, sweatdrops, smile, heart eyes).
- **Girl**: Gorgeous wavy hair with sweet hairpin, large sparkling anime eyes, stylish pastel pink cardigan & pleated skirt, confident expressions (laugh, wink, touched tears, heart eyes).
- **Pinkie (HER Puppy)**: Fluffy cream puppy wearing her signature pink bow. **Interactive**: Tapping Pinkie wags her tail, barks a cute sound, and pops floating love hearts!
- **Luna (HIS Kitten)**: Sleek charcoal kitten with pointy ears and a golden crescent moon collar (`🌙`). **Interactive**: Tapping Luna wags his curled tail, meows, and emits starry sparkles!

## 🛠️ Tech Stack
- **Framework**: Vite + React 19 + TypeScript
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`) + Custom Pixel CSS
- **Animations**: Motion for React (`framer-motion`), Canvas Confetti
- **Icons**: Lucide React
- **Audio**: Web Audio API Synthesizer (Zero external file dependencies)
- **Deployment**: Vercel-ready static export

## 🚀 Development & Deployment Commands

### Prerequisites
- Node.js (v18+)
- npm (v9+)

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
The local server will start at `http://localhost:5173`.

### 3. Build for Production (Vercel Ready)
```bash
npm run build
```
Generates optimized static assets in `dist/`.

### 4. Preview Production Build
```bash
npm run preview
```

### 5. Deploy to Vercel
Simply import this project into [Vercel](https://vercel.com):
- **Framework Preset**: Vite
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
- **Install Command**: `npm install`

## ⚙️ Configuration & Customization
- **Character & Relationship Settings**: Stored in `src/data/characterConfig.ts`.
  - Editable Boy name & Girl name (default: "Him" and "Her").
  - Relationship start date (`relationshipStartDate`): Initially empty until provided. When set, automatically displays the live **Days Together** counter on the landing page!
  - Favorite serial & drama character (default: *Siragu Adika Asai* / *Rohini*).
  - Can also be customized in-app via the **Customize** button on the top right!
- **Story Content**: Stored in `src/data/storyData.ts`. All chapter summaries, dialogues, choices, and teaser quotes can be edited directly.
